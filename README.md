# BHOLU MOBILE
## Omnichannel Sales Performance Dashboard

An interactive Power BI project designed to present and explore omnichannel sales performance for Bholu Mobile.

The dashboard brings sales data into a single reporting view to help users review business performance, compare results across available channels and identify patterns that may support better decisions.

> **Project status:** Dashboard created in Power BI. Add the final dashboard screenshots, source datasets and Power BI file to the folders listed below.

---

## Project Overview

This project demonstrates an end-to-end business intelligence workflow:
- Organising and preparing source data for analysis.
- Building an interactive report in Microsoft Power BI.
- Presenting key performance information in a clear dashboard layout.
- Supporting performance review through visual analysis and filters.

## Tools & Technologies

- **Microsoft Power BI** – data modelling, report development and visualisation.
- **Power Query** – data preparation and transformation (where used in the project).
- **CSV** – source data format.

## How to View the Project

1. Download the `.pbix` file from the `dashboard/` folder.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the CSV files in the `data/` folder.
4. Refresh the data to load the report.

## Data

The `data/` folder is intended to contain the CSV files used by the report. Please refer to the source files for the available fields and data definitions.
